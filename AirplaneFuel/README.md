# Авиапарк — расчёт топлива (C++)

Учебное задание: рассчитать минимальную дозаправку самолёта в пункте B для перелёта **A → B → C**.

## Условия

| Характеристика | Самолёт №1 | Самолёт №2 |
| --- | --- | --- |
| Основной бак | 300 л | 1000 л |
| Временный бак | Нет | 100 л |
| Вес и расход | До 750 кг — 1 л/км; до 1500 кг — 4 л/км; до 2000 кг — 7 л/км | До 1000 кг — 2 л/км; до 2000 кг — 4 л/км; до 3000 кг — 6 л/км |
| Более тяжёлый груз | Не взлетит | Не взлетит |

**Предположение:** в пункте A все имеющиеся баки заправлены полностью. Самолёт №2 сначала использует топливо временного бака. В пункте B временный бак сбрасывается (даже если в нём осталось топливо), а дозаправить можно только основной.

## Файлы

- [main.cpp](main.cpp) — решение задачи.

Код использует конструкции из конспекта: обычные массивы, **двумерные массивы**, циклы `while` и `for`, условия `if / else`, `std::cin` и `std::cout`.

Для запуска на Windows создайте консольный проект C++ в Visual Studio и вставьте содержимое `main.cpp` в исходный файл проекта. Используется `Windows.h` для отображения русского текста в консоли.

## Как устроен расчёт

1. Двумерный массив `weightLimits[2][3]` хранит границы веса для каждого самолёта.
2. Двумерный массив `fuelPerKm[2][3]` хранит соответствующий расход.
3. Массив `distance[2]` хранит расстояния A–B и B–C.
4. Считается нужное топливо для каждого участка: `расстояние * расход`.
5. Если для A–B не хватит основного и временного баков либо для B–C не хватит полностью заправленного основного бака, полёт невозможен.
6. Из затрат на A–B сначала вычитается топливо временного бака; остальное расходуется из основного.
7. Минимальная дозаправка: `max(0, нужное_на_BC - остаток_основного_бака_в_B)`. В программе этот расчёт сделан обычным `if`, без использования `max()`.

## Примеры для проверки

| Самолёт | A–B, км | B–C, км | Груз, кг | Результат |
| --- | ---: | ---: | ---: | --- |
| №1 | 100 | 250 | 500 | Дозаправка 50 л |
| №1 | 100 | 50 | 750 | Дозаправка 0 л |
| №1 | 80 | 10 | 1500 | Невозможен A–B: требуется 320 л, доступно 300 л |
| №1 | 10 | 80 | 1500 | Невозможен B–C: требуется 320 л, бак 300 л |
| №2 | 10 | 500 | 1000 | Дозаправка 0 л; 80 л временного бака сбрасываются |
| №2 | 500 | 500 | 1000 | Дозаправка 900 л |
| №2 | 550 | 500 | 1000 | Дозаправка 1000 л |
| №2 | 551 | 1 | 1000 | Невозможен A–B: нужно 1102 л, имеется 1100 л |
| №2 | 1 | 501 | 1000 | Невозможен B–C: нужно 1002 л, бак 1000 л |
| №2 | 10 | 10 | 3001 | Груз слишком тяжёлый |

После расчёта программа предлагает новый выбор самолёта. Выход из программы — `0`.
